# 思而学：产品与内容设计

## 1. 产品定位与当前范围

**思而学（SiErXue）**是一款教材驱动、离线优先的英语学习 Android App。学习主线不是零散刷题，而是沿固定课程持续推进：

> 选择分册 → 继续一课的五段学习 → 课内练习与跟读 → 自动进入复习队列 → 阶段性测评 → 五维能力反馈

阶段 A 交付可安装 APK：完整的入门 A1 一册 8 课、五段式课程、练习/错题/测评/成绩、系统 TTS、录音识别跟读评分、OpenAI 双接口与全局学习助手「小思」。A2/B1/B2 提供完整分册和课程目录简介，不用空白页冒充内容。

## 2. 教材驱动的信息架构

### 2.1 内容层级

- **Book（分册）**：入门 A1、基础 A2、进阶 B1、高阶 B2。
- **Unit（课）**：每册规划 8～12 课，首版每册 8 课；一课即一个学习单元，目标 20～30 分钟。
- **LessonSection（课段）**：每课固定五段，顺序不可打乱：发音 → 句型结构 → 常用语 → 词汇 → 读写任务。
- **支撑环节**：练习、错题、复习、测评、小思全部归属到课和课段，不形成与教材平行的随机题库主线。

### 2.2 页面流与职责

| 页面 | 职责与关键交互 |
|---|---|
| 首页 | 第一屏显示「继续第 X 册第 Y 课」、五段进度与预计时长；依次展示今日复习、五维能力雷达、下一步建议及课程/错题/测评/小思入口 |
| 课程目录 | 按册展示 8 课树状目录、简介、完成状态和锁定状态；上一课完成解锁下一课，允许确认后手动跳课 |
| 课程详情 | 展示一课固定五段、每段完成状态和开始/继续按钮；完成后回到本页并刷新进度 |
| 段内学习页 | 按段类型渲染发音、句型、常用语、词汇或读写内容；所有英文材料可朗读 |
| 练习与解析 | 只呈现本课/本段练习，逐题判分、即时解析、结束正确率；答错进入错题本 |
| 今日复习 | 复习本课已经学过的词、句型和跟读句，不生成新题库；显示本课 N 个词 + M 个句型 |
| 错题本 | 按册、课、段筛选，单题重做、移除并回溯原课段 |
| 测评 | 每 4 课一次单元测，只考对应 4 课；每册末综合测只考本册，包含口语任务与一篇长阅读 |
| 成绩统计 | 展示测评历史、平均分、最高分、正确率和课/段薄弱点 |
| 设置 | 分册、系统语速、小思语速、悬浮球、双 AI 接口、语音数据、清除对话和学习数据 |

小思以应用内悬浮球和底部抽屉覆盖所有页面；不是系统悬浮窗，不申请 `SYSTEM_ALERT_WINDOW`。

### 2.3 继续学习与锁定

- 首页取当前分册中第一个「五段未全部完成」的课；若均完成则定位到下一可学课或册末综合测。
- 每段完成写入 SectionProgress；课完成条件为五段全部完成或按规则跳过。
- 顺序锁定只影响直接开始学习，不隐藏目录；用户可查看后续简介并确认跳课。
- 有到期复习时，首页首先提示「今日复习：本课 N 个词 + M 个句型」；点击继续新课会先进入复习，允许用户明确选择稍后再学。

## 3. 每课固定五段

### 3.1 发音

内容包括音素讲解、最小对立对、重音与节奏、2～3 个跟读句。喇叭可朗读单词、对立对和句子。

第一版必须实现跟读闭环：

1. 用户点击跟读后，才申请 `RECORD_AUDIO` 权限；拒绝只影响跟读，不影响其他功能。
2. 使用系统 `SpeechRecognizer`，语言为英语并设置 `EXTRA_PREFER_OFFLINE=true`；优先设备已安装的离线识别能力，不引入额外模型。
3. 录音结束后取识别文本，与标准句进行词级编辑距离对齐，记录漏词、错词、增词和可能的词序问题。
4. 根据有效录音时长计算 WPM；输出 0～100 分、逐类问题标注、识别文本和语速。
5. 无识别引擎、离线数据不足或识别失败时明确提示并允许跳过；不把云端 AI 当作评分前置条件。

### 3.2 句型结构

每课一个核心句型，配 2～3 个变体和替换造句练习。句型与例句可朗读；替换练习有明确参考答案，相关客观题归入本段。

### 3.3 常用语

围绕点餐、问路、寒暄、表达观点等一个场景提供功能句、中文释义和简短对话。常用语作为复习与口语任务素材，不另建脱离课程的话术库。

### 3.4 词汇

A1 每课 8 个词（数据模型支持 8～12 个），字段包括词形、音标、中文释义、搭配、词根/构词提示和例句。单词卡与例句均可朗读，点击单词会把该词注入小思上下文。

### 3.5 读写任务

- 短文长度随课递增，提供整段朗读、拆句、主旨/细节/推断题和本地解析。
- 每课一个复述或角色扮演口语任务，复用系统识别与 TTS；提供可参考的简短示例。
- 精读题与口语任务结果进入五维能力评分；答错客观题进入错题本。

## 5. 数据模型

### 5.1 教材与进度

| 实体 | 主要字段 | 关系与说明 |
|---|---|---|
| Book | id、code、title、description、sortOrder、outlineOnly | 一册包含 8～12 课 |
| Unit | id、bookId、number、title、description、durationMinutes、sortOrder | 一课固定关联五个 LessonSection |
| LessonSection | id、unitId、type、title、contentJson、sortOrder | type 固定为 PRONUNCIATION / PATTERN / EXPRESSIONS / VOCABULARY / READING |
| SectionProgress | sectionId、unitId、completed、skipped、score、updatedAt | 首页续学与五段状态的事实源 |
| Vocabulary | id、unitId、sectionId、word、phonetic、meaning、collocation、rootTip、example | 每课 8～12 词，属于词汇段 |
| Passage | id、unitId、sectionId、title、content、mainIdea、sentenceJson | 读写段精读材料与拆句 |
| Question | id、unitId、sectionId、passageId?、type、assessmentScope、prompt、optionsJson、stemsJson、answerJson、explanation、difficulty、sortOrder | 同时保留单选、多选、填空、判断、排序、匹配和阅读小题；scope 为 LESSON / UNIT_TEST / BOOK_TEST |

WrongQuestion 通过 Question 的 unitId、sectionId 回溯教材，不维护第二套分类。

### 5.2 复习、口语与能力

| 实体 | 主要字段 | 说明 |
|---|---|---|
| ReviewItem | id、unitId、sectionId、sourceId、type、content、dueAt、stage、proficiency、updatedAt | 来源仅限本课词、句型、跟读句；五段完成时自动生成 |
| SpeakingAttempt | id、unitId、sectionId、standardSentence、recognizedText、score、issuesJson、durationMillis、wordsPerMinute、createdAt | 保存每次真实识别结果与评分证据 |
| AbilityScore | id、bookId、pronunciation、grammar、vocabulary、speaking、reading、createdAt | 五维分值快照，首页读取当前册最新快照 |
| PracticeRecord | id、questionId、answerJson、isCorrect、mode、answeredAt | 每次客观题作答记录 |
| WrongQuestion | questionId、wrongCount、reviewStage、lastWrongAt、nextReviewAt、updatedAt | 重复错误累计并支持 1/3/7/15 天错题复习 |
| Exam | id、bookId、lessonIdsJson、scope、questionIdsJson、startedAt、durationSeconds、submittedAt、score、correctCount、totalCount、status | 保存组卷边界与题目快照 |
| ExamAnswer | id、examId、questionId、answerJson、isCorrect | 每题明细，未答按错误 |
| AssistantConversation / AssistantMessage | 会话元数据、角色、内容、精简上下文、时间、错误状态 | 小思本地历史，不保存 Key |

种子 JSON 在首启事务性导入 Room；内容版本变化时事务性替换教材，学习记录与配置不被静默清空。

### 5.3 设置和密钥

DataStore 保存当前册、续学位置、语速、悬浮球和双接口非敏感配置。两组 API Key 分别存 EncryptedSharedPreferences，不回显、不写日志、不进入 Room 或导出数据。

## 6. 练习、错题与复习

### 6.1 判分

单选/判断要求唯一选项一致；多选要求集合完全相等；填空忽略首尾空格、连续空白与大小写；排序要求序列一致；匹配按左侧 stems 顺序比较右侧 optionId；阅读材料不单独计分，其主旨、细节、推断小题独立判分。

### 6.2 错题

普通练习答错自动入库，重复答错累计 wrongCount 并重置到 1 天后。错题重做正确按 1/3/7/15 天推进，最后阶段完成后移出活跃错题；普通练习偶然答对不自动移除。错题筛选和报告始终显示所属课与段。

### 6.3 课内复习

一课五段完成后，为该课每个单词、核心句型及跟读句创建 ReviewItem。首次到期为 1 天后，熟练复习按 1/3/7/15 天推进；遗忘则回到 1 天，proficiency 降一级。复习页面直接展示原内容、读音和例句，不生成新题。首页按当天 dueAt 统计词与句型数量。

## 7. 测评边界与成绩

- **课内练习**：只取本课 LESSON 题。
- **单元测**：第 4、8 课后开放；lessonIds 只能包含刚完成的连续 4 课，题目只取这些课中 UNIT_TEST 及允许的课内题。
- **综合测**：lessonIds 为本册全部 8 课，题目只取 BOOK_TEST；另附本册口语任务与第 8 课长阅读，不跨册抽题。
- 不再从全题库无边界随机抽题。组卷顺序可打乱，但范围快照不可变。
- 客观题等权百分制，60 分及格；倒计时结束自动交卷，未答按错。
- 报告按课和段展示正确率，优先建议复习最低分课段；成绩统计保留每次报告。

## 8. 五维能力评分

各维度均为 0～100，首页 Canvas 绘制五轴雷达图。没有表现的维度显示实际完成度，不伪造高分。

| 维度 | 数据来源与权重 |
|---|---|
| 发音 | 跟读平均分 70% + 发音段完成率 30% |
| 语法/句型 | 句型段练习正确率 70% + 句型段完成率 30% |
| 词汇 | 词汇练习正确率 50% + 复习熟练度 30% + 词汇段完成率 20% |
| 口语 | 口语/复述识别平均分 60% + 发音与读写口语任务完成率 40% |
| 阅读 | 精读题正确率 70% + 读写段完成率 30% |

某类暂无任何记录时对应表现项按 0 计，并在建议中引导先完成第一课相关段。每次跟读、练习、课段完成或复习后生成新快照。下一步建议选择最低维度；同分优先发音、句型、词汇、口语、阅读顺序，并给出可执行动作。

## 9. 发音、OpenAI 双接口与缓存

### 9.1 SpeechEngine 双实现

业务只依赖 SpeechEngine。SystemTtsEngine 默认使用系统 TextToSpeech，语言为美式英语、语速 0.7～1.3；OnlineTtsEngine 是可选增强。OfflineTtsEngine 仅留扩展位，首版明确返回未启用且设置页不显示假开关。

在线开启且 Key 完整时优先 `/audio/speech`，失败自动回落系统 TTS。响应流式写入临时文件，再原子改名为私有缓存并用 MediaPlayer 播放。缓存键为 BaseURL、模型、音色、格式、语速和文本的 SHA-256，不含 Key；同文本同参数不重复请求。系统语音缺失时提供安装入口；页面离开停止本页发音，Activity onStop 停止全部。

### 9.2 两套独立多端点配置

对话支持 1～5 个端点，在线 TTS 支持 1～3 个端点。每个端点独立保存名称、BaseURL、模型、加密 Key、主力标记、启用开关和每分钟请求上限；列表顺序即切换优先级，可在设置中上移/下移。不同端点允许共用 Key。旧版单端点配置和 Key 首启自动迁移为首项，不回显明文。

| 配置 | 对话端点 | 在线 TTS 端点 |
|---|---|---|
| 数量 | 1～5 | 1～3 |
| 用途 | 深度解析、出题、写作反馈、小思 | 在线音频合成 |
| 其他 | 主力与备用、独立限流 | 独立音色 voice、mp3/wav、独立限流 |
| 测试 | 每个端点独立测试 `/chat/completions` | 每个端点独立测试 `/audio/speech` |

BaseURL 仅允许 HTTPS。两组端点、健康记录、令牌桶和冷却完全独立。Key 仅作为 Authorization 头发往对应用户端点，不进入日志、健康摘要或导出数据。

### 9.3 重试、限流、熔断与降级

| 场景 | 参数与行为 |
|---|---|
| 非 429 网络错误 | 连接/读写超时、SocketTimeout、IOException、500/502/503/504；单端点最多 3 次，指数退避基数 1 秒、上限 8 秒并加 0～250ms 抖动 |
| 配置错误 | 400/401/403/404/422 不盲目重试，提示检查端点、Key 和模型名 |
| 短时 429 | 同端点最多 5 次尝试，短间隔 1s → 2s → 3s → 4s；连续 3 次后按优先级轮换，之后可在端点间返回重试；跨端点最多 8 次或约 20 秒 |
| Retry-After | 支持秒、HTTP 日期、`x-ratelimit-reset-requests/tokens` 的 ms/s/m 复合格式；≤8 秒优先遵循，>8 秒按短间隔或轮换，避免长时间等待 |
| 429 冷却 | 连续 429 的端点冷却后暂停 90 秒，结束自动半开；不再使用 15 分钟长冷却 |
| 其他错误熔断 | 连续失败 3 次冷却 10 分钟，半开仅允许 1 次试探，成功恢复 |
| 额度耗尽 | 响应体含 insufficient_quota、quota exceeded、exceeded your current quota、billing 时停止该端点重试并禁用，直到手动恢复；提示切换端点或更换 Key |
| 超时 | OkHttp `callTimeout=25s`，流式首字节/读取间隔超时 12s；共享连接池、HTTP/2、`retryOnConnectionFailure=true` |
| 流式中断 | 未收到正文前按普通重试；已有正文后不从头重试，保留内容并标注「回答中断」，提供「继续」 |
| 全部失败 | 不弹窗，使用现有课程解析/同类题，回答首行轻量标记「离线回答」 |

每个端点有独立令牌桶，默认 20 次/分钟，可设置 10～60。桶只用于批量/自动任务的预先节流；用户主动发送不直接失败，429 重试不重复扣减令牌。该默认值是否偏保守需实测后调整。批量任务串行并加入 300ms±100ms 抖动；非实时失败任务通过 WorkManager + CONNECTED 约束在网络恢复后最多执行 2 次，实时对话不后台补发。

解释/翻译等纯查询按“问题 + 精简上下文”使用内存 LRU（32 项、5 分钟），30 秒内的重复查询直接复用；出题结果不缓存。system prompt 保持短文本，历史最多 6 条，`max_tokens≤800`。

设置页「通道健康」显示最近成功、错误摘要、连续失败、最近 429、当前桶余量与剩余冷却时间，支持单独测试和「恢复并重置」。小思状态点：绿=主力正常，黄=重试/备用，红=全部失败的离线兜底；手动重发保留原问题。

## 10. 小思：全局学习助手

- Compose 根层常驻 56dp 半透明悬浮球，可拖动并吸附最近左右边缘；思考中有进度，面板关闭收到回复有未读点。
- ModalBottomSheet 支持文字、可用的系统语音识别输入、历史、新会话、清空和隐藏；回复可朗读并采用独立小思语速。
- 页面只登记结构化上下文：当前册/课/段、单词/例句、题干/选项/所选答案、错题次数。面板顶部同步显示「正在看：某词」或「正在做：第 N 题」。
- 快捷动作：解释当前句型或课段、出 3 道同类题、讲讲这道错题、翻译并朗读。
- 系统提示词约束小思为英语助教，默认简洁中文、必要时给音标和短例句，不编造上下文、不索取隐私。
- 会话与回复存 Room；只把当前问题、必要历史和精简上下文发送到用户自配接口。无 Key 时使用本课讲解/解析和内置同类题，失败保留兜底并显示重试。

## 11. 可插拔模型与资源

小思只依赖 ChatProvider：RemoteChatProvider 在配置完整时调用云端；OfflineFallbackProvider 提供本地内容；LocalModelProvider 首版仅返回「未启用」，不进入主链路。未来增加实现和设置项即可，UI 不依赖具体 Provider。

ModelAssetStore 统一抽象模型/语音资源的下载、SHA256 校验、删除和占用统计。阶段 A 仅实现私有空目录管理与校验，不联网下载，不引入 NDK/JNI 或模型文件。

## 12. 版本路线

### 阶段 A（当前）

教材骨架与主链路、完整 A1 8 课、练习/错题/测评/成绩、系统 TTS、真实系统语音跟读评分、云端 OpenAI 双接口和小思。产出可安装 APK。本地对话模型与 sherpa-onnx 只留接口。

### 阶段 B

扩充其余分册至「够学」的内容量，打磨小思上下文联动、对话历史与成绩趋势。

### 阶段 C：本地对话模型

确定采用 **Qwen3-0.6B-Instruct Q4_K_M（约 400 MB）**，优先 llama.cpp Vulkan 后端，CPU 兜底，通过 JNI 接入。模型不打包进 APK：设置页按需下载、显示大小、SHA256 校验、删除与占用；引擎可在云端/本地/离线兜底间切换并按优先级回落，推理仅在前台进行。

目标机型为 **8GB+ 内存手机（小米 14 一类）**；4GB 车机不在支持范围内。

### 阶段 D：离线发音

采用 **sherpa-onnx + VITS/Piper 小模型**，中英模型各一个、按需下载。设置中提供系统 TTS / 在线 TTS / 离线 TTS，默认系统优先；选择离线后失败回系统，选择在线后失败可依次回离线、系统，所有回落均有状态反馈。

## 13. 清除与降级

清除对话只删小思会话；清除学习数据删除课段进度、练习、错题、复习、口语、能力快照、测评、小思和音频缓存，保留教材与配置。AI 对话失败回本地解析，在线 TTS 失败回系统，语音识别不可用允许跳过；任何网络能力都不决定本地课程是否可用。
